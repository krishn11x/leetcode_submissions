# Max Sum Subarray of Size K

## Problem Statement

Given an array of integers `arr[]` and an integer `k`, return the **maximum sum of a subarray of size `k`**.

A **subarray** is a contiguous part of an array. This means the elements in the subarray must be next to each other.

The subarray must contain exactly `k` elements.
