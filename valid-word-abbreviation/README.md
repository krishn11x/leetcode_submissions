# Valid Word Abbreviation

## Problem

Given a string `word` and an abbreviation `abbr`, determine whether the abbreviation is valid for the given word.

## Example

Input:
word = "internationalization"
abbr = "i12iz4n"

Output:
true

## Approach

Use two pointers to traverse the word and abbreviation while validating each character and numeric abbreviation segment.

## Complexity

- Time: O(n)
- Space: O(1)
